# Rule: Project Visual Style & Color System

Whenever styling components, pages, or building new features, follow the **Dark Espresso & Warm Mocha** design system defined in `STYLE_GUIDE.md`:

1. **Background**:
   - Default page background canvas is Deep Dark Espresso (`#141211`).
   - Cards and containers use Elevated Dark Glass (`#221E1C` / `#25201E`) with translucent borders (`rgba(255, 255, 255, 0.08)`).

2. **Colors**:
   - Primary Action Accent: Warm Mocha (`#8C5A4C`) / Hover (`#9E6756`).
   - Primary Text: Warm Cream (`#F5EFEA`).
   - Secondary / Muted Text: Warm Taupe (`#A39890`).
   - Highlight Tag: Warm Amber (`#D98A5B`).

3. **Typography**:
   - Headers: Fraunces (Serif).
   - Functional UI & Labels: Public Sans / Inter (Sans-serif).
   - Prices & Numeric Data: JetBrains Mono (Monospace).
